# AppNinjaBot

## 📱 О проекте
AppNinjaBot - это комплексное решение для управления задачами и автоматизации бизнес-процессов, состоящее из веб-интерфейса и Telegram бота. Система предоставляет удобный интерфейс для работы с задачами, планировщиком и интеграцию с различными сервисами.

## 🛠 Используемые технологии

### Frontend (React приложение)
- **React 18** - JavaScript библиотека для построения пользовательских интерфейсов
- **TypeScript** - Типизированный JavaScript для надежной разработки
- **Material-UI (MUI)** - Библиотека компонентов для современного UI
- **Redux Toolkit** - Управление состоянием приложения
- **Socket.IO Client** - Реализация WebSocket для real-time коммуникации
- **Styled Components** - Стилизация компонентов
- **React Router** - Маршрутизация в приложении
- **Handsontable** - Работа с табличными данными
- **Framer Motion** - Анимации интерфейса

### Backend (Python сервер)
- **Flask** - Легковесный веб-фреймворк
- **Python Telegram Bot** - Библиотека для создания Telegram ботов
- **Flask-SocketIO** - WebSocket сервер для real-time коммуникации
- **APScheduler** - Планировщик задач
- **Pandas** - Обработка и анализ данных
- **OpenPyXL & XlsxWriter** - Работа с Excel файлами
- **Gevent** - Асинхронный WSGI сервер

## 🚀 Основной функционал

### Веб-интерфейс
- Управление задачами и проектами
- Real-time обновления через WebSocket

## 🔧 Установка и запуск

### Backend
1. Перейти в директорию backend:
```bash
cd backend
```

2. Создать виртуальное окружение и активировать его:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Настроить переменные окружения в файле .env:
```
TELEGRAM_BOT_TOKEN=your_bot_token
DATABASE_URL=your_database_url
```

5. Запустить сервер:
```bash
python app.py
```

### Frontend
1. Перейти в директорию frontend:
```bash
cd frontend
```

2. Установить зависимости:
```bash
npm install
```

3. Настроить переменные окружения в .env:
```
REACT_APP_API_URL=http://localhost:5000
REACT_APP_WS_URL=ws://localhost:5000
```

4. Запустить приложение:
```bash
npm start
```

## 🐳 Docker
Проект также можно запустить с помощью Docker:
```bash
docker-compose up --build
```
