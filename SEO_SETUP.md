## 📋 Что нужно сделать для выхода в топ Google:

### 1. **HTTPS (SSL сертификат) - КРИТИЧНО!**

Google отдает предпочтение сайтам с HTTPS. Нужно настроить SSL сертификат для `flowixdata.ru`.

**Варианты:**
- **Let's Encrypt (бесплатно)** - через Certbot
- **Cloudflare** - бесплатный SSL + CDN
- **Платный SSL** - если нужен extended validation

**Команда для установки Let's Encrypt на сервере:**
```bash
# SSH на сервер
ssh user@79.141.72.224

# Установка Certbot
sudo apt update
sudo apt install certbot python3-certbot-nginx

# Получение сертификата
sudo certbot --nginx -d flowixdata.ru -d www.flowixdata.ru

# Автообновление
sudo certbot renew --dry-run
```

После установки нужно обновить Nginx конфигурацию для редиректа HTTP → HTTPS.

### 2. **Регистрация в Google Search Console**

**Шаги:**
1. Перейдите на https://search.google.com/search-console
2. Добавьте свойство: `https://flowixdata.ru`
3. Подтвердите право собственности одним из способов:
   - **HTML тег** (добавить в `<head>`)
   - **HTML файл** (загрузить на сервер)
   - **DNS запись** (TXT record)
   - **Google Analytics** (если подключен)

4. После подтверждения:
   - Отправьте **sitemap**: `https://flowixdata.ru/sitemap.xml`
   - Проверьте **покрытие индексации** (Index Coverage)
   - Настройте **международное таргетинг** (язык: русский)

5. **Проверьте мобильную адаптивность:**
   - Инструменты → Мобильная адаптивность

---

### 3. **Регистрация в Yandex Webmaster**

**Шаги:**
1. Перейдите на https://webmaster.yandex.ru
2. Добавьте сайт: `https://flowixdata.ru`
3. Подтвердите право собственности (HTML тег или файл)
4. Отправьте sitemap: `https://flowixdata.ru/sitemap.xml`
5. Настройте регион таргетинга (Россия)

---

### 4. **Google Analytics 4**

**Для отслеживания посетителей:**
1. Создайте аккаунт на https://analytics.google.com
2. Получите **Measurement ID** (G-XXXXXXXXXX)
3. Добавьте в `layout.tsx` перед `</head>`:

```tsx
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script
  dangerouslySetInnerHTML={{
    __html: `
      window.dataLayer = window.dataLayer || [];
      function gtag(){dataLayer.push(arguments);}
      gtag('js', new Date());
      gtag('config', 'G-XXXXXXXXXX');
    `,
  }}
/>
```
