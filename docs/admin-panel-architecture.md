# Архитектура админ-панели Flowix Admin Panel

## Обзор

Веб-админ-панель для управления компаниями, ролями, группами и настройками ботов.

**URL:** `https://flowix.app/admin` (или `http://localhost:3000/admin` для разработки)

**Интеграция:** Админ-панель интегрирована в существующий Next.js проект `flowix-landing-ssr`

## Система авторизации

### Типы пользователей

1. **Супер-администратор** (техподдержка)
   - Доступ ко всем компаниям
   - Может создавать/удалять компании
   - Может управлять всеми настройками

2. **Администратор компании**
   - Доступ только к своей компании
   - Может управлять ролями своей компании
   - Может привязывать группы к ролям
   - Может настраивать уведомления

### Авторизация

**Вариант 1: JWT токены (как в основном приложении)**
- Отдельная таблица `admin_users` для админ-панели
- Отдельные JWT токены с префиксом `admin_`
- Роль в токене: `super_admin` или `company_admin`

**Вариант 2: Использование существующих пользователей**
- Проверка роли пользователя в группе
- Если пользователь - `creator` или `administrator` в главной группе компании → доступ к админ-панели
- Супер-администратор определяется через переменную окружения или отдельную таблицу

**Рекомендация:** Вариант 1 (отдельная система авторизации)

## API Endpoints для админ-панели

### Авторизация
```
POST /v1/admin/auth/login
POST /v1/admin/auth/logout
GET  /v1/admin/auth/me
```

### Компании
```
GET    /v1/admin/companies              # Список компаний (для супер-админа)
GET    /v1/admin/companies/{id}        # Детали компании
POST   /v1/admin/companies              # Создание компании (супер-админ)
PUT    /v1/admin/companies/{id}         # Обновление компании
DELETE /v1/admin/companies/{id}         # Удаление компании (супер-админ)
GET    /v1/admin/companies/my           # Моя компания (для админа компании)
```

### Роли
```
GET    /v1/admin/companies/{company_id}/roles           # Список ролей компании
GET    /v1/admin/companies/{company_id}/roles/{id}      # Детали роли
POST   /v1/admin/companies/{company_id}/roles           # Создание роли
PUT    /v1/admin/companies/{company_id}/roles/{id}      # Обновление роли
DELETE /v1/admin/companies/{company_id}/roles/{id}      # Удаление роли
```

### Функции ролей
```
GET    /v1/admin/roles/{role_id}/features               # Функции роли
POST   /v1/admin/roles/{role_id}/features               # Привязать функцию к роли
DELETE /v1/admin/roles/{role_id}/features/{feature_id}  # Отвязать функцию
```

### Группы
```
GET    /v1/admin/companies/{company_id}/groups         # Список групп компании
GET    /v1/admin/companies/{company_id}/groups/{id}     # Детали группы
POST   /v1/admin/groups/{group_id}/assign-role          # Привязать роль к группе
PUT    /v1/admin/groups/{group_id}/role                 # Изменить роль группы
GET    /v1/admin/groups/{group_id}/features              # Функции группы
```

### Уведомления
```
GET    /v1/admin/groups/{group_id}/notifications        # Настройки уведомлений группы
POST   /v1/admin/groups/{group_id}/notifications        # Добавить уведомление
DELETE /v1/admin/groups/{group_id}/notifications/{id}    # Удалить уведомление
```

### Функции бота
```
GET    /v1/admin/bot-features                          # Список всех функций
```

## Структура страниц

### 1. Dashboard (Главная)
- Статистика:
  - Количество компаний
  - Количество групп
  - Количество ролей
- Последние действия
- Быстрые ссылки

### 2. Компании
**Список компаний:**
- Карточки компаний с информацией:
  - Название
  - Бот компании
  - Количество групп
  - Количество ролей
  - Статус (активна/неактивна)
- Фильтры и поиск
- Кнопка "Создать компанию" (для супер-админа)

**Создание/Редактирование компании:**
- Форма:
  - Название компании
  - Токен бота
  - Username бота
  - Главная группа (опционально)
  - Статус активности

### 3. Роли
**Список ролей компании:**
- Карточки ролей:
  - Название роли
  - Код роли
  - Иконка и цвет
  - Количество групп с этой ролью
  - Доступные функции
- Кнопка "Создать роль"

**Создание/Редактирование роли:**
- Форма:
  - Название роли
  - Код роли (автогенерация или ручной ввод)
  - Описание
  - Иконка (выбор из списка или emoji)
  - Цвет (color picker)
  - Порядок отображения
  - Чекбоксы функций:
    - ☑ Инвентаризация
    - ☑ Смены
    - ☑ Закупки
    - ☑ Уведомления

### 4. Группы
**Список групп компании:**
- Таблица групп:
  - Название группы
  - Telegram ID
  - Текущая роль
  - Тип (рабочая/уведомления)
  - Доступные функции
  - Кнопки: "Изменить роль", "Настроить уведомления"

**Привязка роли к группе:**
- Модальное окно:
  - Выбор роли из списка
  - Тип группы:
    - ☑ Рабочая группа (бот работает)
    - ☐ Только уведомления (бот не работает)
  - Кнопка "Привязать"

**Настройка уведомлений:**
- Список функций группы
- Для каждой функции:
  - Рабочая группа (уже выбрана)
  - Группы для уведомлений:
    - Список групп компании
    - Чекбоксы для выбора
  - Тип уведомления (excel, message, file)

### 5. Функции бота
**Управление функциями:**
- Список всех функций системы
- Для каждой функции:
  - Код функции
  - Название
  - Описание
  - Статус (активна/неактивна)
- Только просмотр (функции создаются через миграции)

## Безопасность

### Проверки прав доступа

1. **На уровне API:**
   - Middleware для проверки JWT токена
   - Проверка роли пользователя (super_admin / company_admin)
   - Проверка принадлежности компании (для company_admin)

2. **На уровне фронтенда:**
   - Условный рендеринг элементов UI
   - Редирект на страницу доступа запрещен
   - Скрытие данных других компаний

### Пример проверки прав в API:

```python
async def check_admin_access(
    current_user: AdminUser = Depends(get_current_admin),
    company_id: int = None
):
    if current_user.role == "super_admin":
        return True
    
    if current_user.role == "company_admin":
        if company_id and current_user.company_id != company_id:
            raise HTTPException(403, "Доступ запрещен")
        return True
    
    raise HTTPException(403, "Недостаточно прав")
```

## Развертывание

### Development
```
npm install
npm run dev
# Админ-панель на http://localhost:3001
```

### Production
```
npm run build
# Статические файлы в dist/
# Разместить на nginx или другом веб-сервере
```

### Docker
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3001
CMD ["npm", "run", "preview"]
```

## Миграция данных

При первом запуске админ-панели:
1. Создать супер-администратора (через миграцию или скрипт)
2. Создать базовые функции бота (через миграцию)
3. Импортировать существующие компании и группы (опционально)
