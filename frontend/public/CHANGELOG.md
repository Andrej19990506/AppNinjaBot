# Обновление FloWix

## О приложении FloWix

**FloWix** — это умная система автоматизации для вашего бизнеса. Приложение помогает управлять инвентаризацией, списаниями, поставками и автоматическими отчетами в одной системе. Идеально подходит для магазинов, складов, ресторанов и любых точек продаж. Интеграция с Telegram обеспечивает мгновенные уведомления и удобную работу.

---

## Что нового в этом обновлении

### 🔧 Исправление ошибок записи курьеров

**Полный переход на шаблоны смен**

Мы полностью перевели архитектуру записи курьеров на систему шаблонов. Теперь вместо старых настроек слотов "день/ночь" используется гибкая система шаблонов, которая позволяет настраивать смены для каждого дня недели индивидуально.

**Исправлена запись курьеров старшим курьером**

Ранее при записи курьера старшим курьером шаблон не мог корректно привязаться к смене. Теперь эта проблема полностью решена — старший курьер может записывать курьеров, и шаблон автоматически корректно привязывается к смене.

**Версионирование настроек слотов**

Реализована возможность настройки слотов для текущего периода записи или для следующего. Это решает важную проблему: ранее, когда старший курьер хотел настроить слоты для будущих открытий, изменения касались текущей записи, где курьеры уже были записаны. Это приводило к некорректному отображению, где в интерфейсе пропадали записанные слоты курьеров.

Теперь вы можете выбрать:
- **Текущий период** — изменения применяются сразу (с предупреждением, если курьеры уже записаны)
- **Следующий период** — изменения вступят в силу только с начала следующего периода записи

**Обновлен дизайн**

Интерфейс управления шаблонами смен получил современный и удобный дизайн, адаптированный для мобильных устройств. Теперь работать с шаблонами стало еще проще и приятнее.

### 🌐 Большое обновление: Работа через браузер

**Авторизация через Telegram в браузере**

Теперь вы можете работать с приложением FloWix не только внутри Telegram Mini App, но и через обычный браузер на любом устройстве. Авторизация происходит мгновенно через Telegram, что предотвращает неудобства при работе внутри Telegram Mini App, когда интерфейс Telegram перекрывает приложение при сворачивании.

**Преимущества работы через браузер:**
- Полноэкранный режим без интерфейса Telegram
- Удобная работа на десктопе и планшете
- Возможность установки приложения на устройство (PWA)
- Быстрая авторизация через Telegram-бота

---

### 🤖 Разделение ботов

**Новая архитектура ботов**

Мы разделили функционал ботов для более удобной работы:

- **Основной бот приложения (Flowix)** — используется для авторизации и работы через браузер. Если вам удобно работать внутри Telegram, приложение теперь открывается через бота Flowix.

- **Бот компании** — используется для отправки уведомлений и работы с конкретной компанией. Каждая компания может иметь своего бота для более персонализированной работы.

Это разделение позволяет:
- Более гибко настраивать уведомления для разных компаний
- Использовать разные боты для разных целей
- Улучшить безопасность и управление доступом

---

## Как начать работу

1. **Через браузер**: Откройте приложение в браузере и авторизуйтесь через Telegram-бота Flowix
2. **Через Telegram**: Откройте бота Flowix в Telegram и запустите приложение
3. **Установка на устройство**: В браузере появится предложение установить приложение на ваше устройство для еще более удобной работы
