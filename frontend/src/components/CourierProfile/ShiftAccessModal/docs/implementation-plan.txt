# План внедрения функционала настройки доступа к сменам

## Описание основного функционала

Модальное окно настройки доступа к сменам предоставляет интерфейс для управления временем, когда курьеры могут регистрироваться на смены. Интерфейс разделен на три основных шага и дополнительные настройки.

## Шаг 1: День и время открытия регистрации

- Выбор дня недели (startDay) - определяет в какой день недели открывается доступ
- Настройка времени (startHour и startMinute) - точное время открытия регистрации
- Определяет, когда курьеры могут начинать регистрироваться на смены
- Пользователю предоставляется простой и понятный интерфейс выбора

## Шаг 2: Период доступа

- Выбор типа смещения (offsetType): дни, недели или без смещения
- Величина смещения (offsetAmount) - насколько дней/недель вперед смещать период
- Длительность периода (periodLength) - как долго будет доступна регистрация
- Определяет, на какой период времени открывается регистрация
- Визуализация периода регистрации для наглядности

## Шаг 3: Настройки активности

- Автоматическое закрытие (isAutoClosure) - включение/выключение автозакрытия
- Время закрытия (closureHour и closureMinute) - когда закрывать доступ
- Настройки визуального отображения активных/неактивных периодов
- Индикаторы состояния для наглядности

## Дополнительные настройки

- Календарь исключений — позволяет выбирать конкретные даты, когда доступ к сменам активен
- Еженедельный режим — включает циклическое повторение настроек по неделям
- Постоянная активность — позволяет настроить постоянный доступ ко всем сменам
- Сохранение и загрузка настроек из Redux хранилища

## Технические детали реализации

- Использование styled-components для создания адаптивного интерфейса
- Поддержка навигации между шагами с помощью кнопок и свайпов (для мобильных устройств)
- Валидация пользовательского ввода
- Интеграция с Redux для сохранения настроек
- Адаптивная верстка для различных устройств
- Анимации для улучшения пользовательского опыта

## Этапы разработки

1. Создание базовых компонентов интерфейса с использованием styled-components
2. Реализация навигации между шагами
3. Разработка компонентов для каждого шага
4. Создание компонентов для дополнительных настроек
5. Интеграция с Redux и логикой приложения
6. Тестирование и отладка
7. Оптимизация производительности
